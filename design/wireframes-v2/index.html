Penumbra lo-fi wireframes · round 2

6 screens × 3 new directions, built from docs/IDEA.md, SCIENCE-SPEC.md and ARCHITECTURE.md. Same rules as round 1: greyscale, judge layout and flow, all numbers FAKE. Charts and headline numbers come from one shared fake model (v2.js), so a picture never disagrees with its number. Pick one letter per screen (round 1 or round 2, mixing is fine) and note it in design/DECISIONS.md. The earlier whole-app version is kept in flows/.

1 · Site: horizon panorama + timelines Must

A Lander's-eye viewOpen ↗

Tall panorama at mast height, a close-up of how much Sun disc shows, and an eye-height slider.

+ Makes the two metrics (disc for power, visible for PGDA) obvious. − Live countdowns are smaller.

from: SCIENCE-SPEC 1b, IDEA science model 3

B Countdown firstOpen ↗

Four big live clocks (Sun and Earth elevation, next sunset and Earthset with ±), panorama and timelines below.

+ Exactly the Must "large live readout". − Panorama gets less room.

from: IDEA Must tier, SCIENCE-SPEC 1f

C Which ridge casts the shadowOpen ↗

Horizon shaded by distance (near 20 m tile vs far 240 m tile), a range chart, and the ridges that set each sunset.

+ Explains why; uses the horizon's dist_m output. − More for experts than the public.

from: ARCHITECTURE 3.2 horizon layout

2 · Planner: inputs + survival headline Must

A Step by stepOpen ↗

Site → date → lander → answer, with preset cards and the answer previewing as you choose.

+ Easiest for first-time users and judges. − Slow for repeat runs.

from: IDEA Decisions (presets, "assumed" labels)

B What changes whatOpen ↗

Each input shows what it reruns (horizon / timeline / survival); a big battery chart; a bar chart of which input matters most.

+ Teaches the model and answers "what if" fast. − Busiest of the three.

from: ARCHITECTURE 1.4 rerun table · builds on round-1 Planner C

C Landing-date calendarOpen ↗

For one pin: operable days for every landing date 2026–2030, the best windows listed, the chosen date in detail.

+ Answers "when should we land" in one picture. − Many model runs per pin.

from: IDEA Decisions (dates 2026–2030)

3 · Terrain Should

A Shadow sweepOpen ↗

3D with a day-by-day film strip and play button; readout of shadow-edge distance and when it reaches the pin.

+ The video shot. − Needs 3D (cut order 1).

from: IDEA build roles (cinematographer)

B Region heatmap rankingOpen ↗

100 m cells coloured by operable days, top cells with slope, and the best cell within 1 km of IM-2.

C Cross-section to the SunOpen ↗

Terrain profile from the pin toward the Sun, with the mast, the Sun ray, the blocking ridge and the Moon's curvature.

+ Cheap to build, very clear. − Shows one direction at a time.

from: SCIENCE-SPEC 1a (curvature)
