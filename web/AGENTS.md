# web/

- Svelte 5 runes (`$state`, `$derived`, `$props`).
- `src/lib/wasm/` is generated by `bun run wasm` at the repo root; regenerate it, never edit it.
- Visuals equal the computed numbers: shading and charts read model output, never GPU shadow maps.
- Styling uses the tokens in `design/DESIGN.md`.
- Check with `bun run check` (svelte-check); build with `bun run build`.
- Import the engine only from `src/lib/engine.ts`. Never hold a view into WASM memory.
